## Локальный запуск

Из корня репозитория запустите локальный HTTP-сервер.

```bash
python3 -m http.server 8000
```

Откройте [http://localhost:8000](http://localhost:8000). Проект состоит из HTML, CSS и JavaScript и работает без установки зависимостей.
